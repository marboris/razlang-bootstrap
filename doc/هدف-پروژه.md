# هدف پروژه

راز یک پروژه‌ی bootstrap این است که Stage-0 فقط آغاز راه باشد: Node.js کامپایلر اولیه را اجرا می‌کند، اما کامپایلر واقعی باید با خود Raz نوشته شود و بتواند خودش را بسازد.

در این پروژه، AST و تحلیل معنایی به یک IR مستقل از مقصد تبدیل می‌شوند و C++ فقط یکی از backendهاست. معیار موفقیت نهایی این است که یک نسخه‌ی native از کامپایلر بتواند سورس کامپایلر را دوباره کامپایل کند و خروجی پایدار و معادل تولید شود.

مطالعه‌ی پیشنهادی: Compiler، Bootstrapping (compilers)، Self-hosting، LLVM و MLIR.
