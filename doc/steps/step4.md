### مدل نهایی نسل‌ها

قرارداد نهایی پروژه این است که **نسل `n` فقط یک‌بار با نسل `n-1` ساخته می‌شود**. بعد از freeze، خود `gen_n` compiler عملیاتی زبان `L_n` است: برنامه‌های `L_n` را کامپایل می‌کند و `S_{n+1}` را برای ساخت نسل بعد می‌سازد.

```text
gen0 -- S1 --> gen1 -- S2 --> gen2 -- S3 --> gen3
                    │
                    └-- programs written in L1
```

بنابراین `gen1` لازم نیست `S1` را دوباره کامپایل کند. یک نسل می‌تواند در نسل بعد API یا حتی بخشی از syntax قدیمی را تغییر دهد؛ این breaking change مجاز است، چون هدف هر نسل ساخت نسل بعد و پشتیبانی از زبان همان نسل است.
