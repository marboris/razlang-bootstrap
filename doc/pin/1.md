# The Raz Programming Language

**Raz** is a general-purpose, statically typed, compiled programming language designed for performance, readability, and memory safety.

Raz combines low-level control and runtime efficiency inspired by C and C++, readable syntax influenced by scripting languages, and type-system concepts from functional programming. Its toolchain aims to provide integrated compilation, dependency management, and native executable generation.

Key goals include:

- **Performance:** Native compilation and efficient resource usage.
- **Memory safety:** Safer memory management without relying on a conventional garbage collector.
- **Concurrency:** Support for high-performance networking and parallel workloads.
- **Developer experience:** Readable syntax, modular libraries, and integrated build tools.
- **Self-hosting:** A compiler capable of compiling its own source code, with LLVM as a planned compilation target.

## Syntax

Raz uses explicit declarations, function return types, module imports, and a concise expression syntax.

```raz
use std.io;

function main() -> i64 {
    print("Hello, Raz!");
    return 0;
}
```

Compile-time definitions use `define`:

```raz
define twice(x) { x + x }

let result: i64 = twice(21);
```

## Keywords

The language includes declarations, control flow, module imports, and compile-time definitions.

| Category | Examples |
|---|---|
| Declarations | `function`, `let`, `const` |
| Control flow | `if`, `else`, `while`, `return` |
| Modules | `use` |
| Compile-time definitions | `define` |
| Native interoperability | `!` call syntax |

The supported keyword set and semantics are defined by the current compiler implementation and may evolve.

## Types

Raz uses static types to enable compile-time checking and efficient native code generation.

| Type category | Examples |
|---|---|
| Integers | `i64` |
| Strings | `string` |
| Collections | `List<T>` |
| References | `Ref<T>` |
| Boolean | `bool` |
| Inference | `let value = expression;` |

The type system is under development. Full ownership and borrowing rules, comprehensive memory-safety guarantees, and a complete family of fixed-width integer types remain future goals.

## Tools

The Raz toolchain is designed to provide a unified development workflow.

- **`razc`** — Compiler driver for Raz source files and native compiler options.
- **GNU C++** — Current native compilation backend, translating generated C++ into executables.
- **Make and CMake** — Build orchestration.
- **Ninja** — Fast incremental builds.
- **CTest** — Native integration and regression testing.
- **LLVM** — Planned compiler backend.

Raz supports inspecting generated C++ while retaining a direct path to native executable generation.

## Examples

### Variables and functions

```raz
function add(a: i64, b: i64) -> i64 {
    return a + b;
}

let result: i64 = add(20, 22);
```

### Modules

```raz
use std.io;

function main() -> i64 {
    print("Native compilation with Raz");
    return 0;
}
```

### Build configuration

```bash
razc app.raz -O2 -g -march=native -o app
```

Compiler options are forwarded to the native C++ toolchain where supported.

## Web app

A browser-based Raz playground is a potential extension of the toolchain. It could provide an editor, syntax highlighting, compilation diagnostics, and an option to inspect generated C++.

A hosted playground and its execution environment are not considered established features until implemented.
